Travail pratique #1 (10%) - Visualisation de données


Objectif

Développer un script Python autonome (stand-alone) permettant de visualiser les données
contenues dans un fichier JSON. Le travail vise à se familiariser avec le langage Python ainsi
qu'à explorer la manipulation de données. Le script devrait nécessiter un seul fichier et être
appelé avec un seul paramètre. L'utilisation de la librairie graphique PySide6 est requise pour
créer l'interface.


Consignes

● Charger en mémoire les données issues d’un fichier JSON reçu en paramètre. Le chargement devra être en
mesure de gérer les erreurs des données.

● Implémenter une interface permettant d’afficher les données sous forme de tableau.

● Implémenter le tri en ordre croissant et décroissant par colonne.

● Implémenter une fonctionnalité de recherche.

● Afficher le nom, la taille en mémoire et le nombre d’éléments du fichier.

● Suivre les standards de programmation vus en classe tels que les conventions de noms, de structure des
fonctions (PEP8), Etc.

● Réaliser une rencontre individuelle de 5 minutes maximum avec l’enseignant afin de valider l’authenticité
du code (sans IA, fait par vous)
